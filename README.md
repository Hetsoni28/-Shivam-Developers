# Shivam Developers — Dynamic Website Starter

Production-oriented starter architecture based on the approved demo.

Stack:
- Next.js + TypeScript
- Tailwind CSS
- Atomic Design
- Lucide React
- Framer Motion
- Three.js / React Three Fiber
- Sanity CMS

No custom backend or admin dashboard is included. Sanity is the CMS/content layer.

## Structure

src/
  app/
  components/
    atoms/
    molecules/
    organisms/
    templates/
    3d/
  lib/
  sanity/

## Run

npm install
npm run dev

Sanity environment variables are documented in `.env.example`.

This starter intentionally uses placeholders for project media and company contact details.
